#+title: Neron Themes

# Created: As package 2026-03-03 (originally from dotfiles 2022-07-07)

A pair of colorful neon-pastel themes for Emacs (dark and light).

The name "Neron" refers to a interpretation of the number 666 as a
cipher for "Neron Caesar" in Hebrew gematria/isopsephy.

* Installation

The repository contains pre-generated, standalone theme files. You can
install directly from git using your preferred package manager.

** package.el (Emacs 29+)
#+begin_src emacs-lisp
(unless (package-installed-p 'neron-themes)
  (package-vc-install "https://codeberg.org/11xx/neron-themes"))
#+end_src

** straight.el
#+begin_src emacs-lisp
(straight-use-package
 '(neron-themes :host codeberg :repo "11xx/neron-themes"))
#+end_src

** Elpaca
#+begin_src emacs-lisp
(elpaca (neron-themes :host codeberg :repo "11xx/neron-themes"))
#+end_src

* Usage

The package automatically adds its installation directory to
=custom-theme-load-path=.

Available themes:
- =neron-dark=
- =neron-light=

e.g.
: (load-theme 'neron-dark)
: (load-theme 'neron-light)

-----

Example usage with [[https://www.emacswiki.org/emacs/SetupEl][setup.el]] + [[https://github.com/progfolio/elpaca][elpaca]] + [[https://github.com/LionyxML/auto-dark-emacs][auto-dark]]:
#+begin_src emacs-lisp
(elpaca (neron-themes :host codeberg
                      :repo "11xx/neron-themes"
                      :files ("neron-*.el")))

(setup (:elpaca auto-dark)
  (setopt auto-dark-themes '((neron-dark)
                             (neron-light)))
  (:hook-into elpaca-after-init-hook)
  (:hide-mode))
#+end_src

* Customization

The themes use a shared runtime engine (=neron-theme-base.el=) that
automatically calculates nearest-match 256-color and terminal
fallbacks from hex values.

To edit a theme you can change the palettes and faces (with simplified
syntax) directly in =neron-*-theme.el=.

** Creating Variants
To define a new variant, simply create a new file
(e.g. =neron-myvariant-theme.el=), define a palette and overrides, and
pass them to =(neron-theme-create)=:
#+begin_src emacs-lisp
;;; neron-myvariant-theme.el
(require 'neron-theme-base)

(deftheme neron-myvariant "My custom Neron variant.")

(let ((my-colors
       '((bg-primary      "#222222")
         (bg-secondary    "#27282c")
         (bg-hl           "#2f2f2f")
         (bg-selection    "#355565")
         (fg-primary      "#a6a8a9")
         (fg-secondary    "#cccccc")
         (fg-muted        "#707070")
         (accent-blue     "#69aaff")
         (accent-cyan     "#00bbb7")
         (accent-green    "#61bd09")
         (accent-magenta  "#ff77cf")
         (accent-orange   "#fd892c")
         (accent-purple   "#a89bff")
         (accent-red      "#f88785")
         (accent-warning  "#d2a022")
         (accent-yellow   "#b8aa07")
         ;; misc
         (bg-diff-added   "#152615")
         (bg-diff-removed "#301d1e")
         (bg-diff-header  "#092147")
         (border          "#404047")
         (cursor          "#4455bb")
         (comment         "#bda38e")))

      (my-overrides
       '((match :foreground "white" :background bg-muted
                :weight bold :slant i
                :box (:line-width 1 :color border)
                :underline (:style line :position -5))
         (isearch-fail :background "red" :foreground "white" :inherit match)
         (vertico-current :foreground "white" :background bg-muted
                          :weight bold :slant o :extend t)
         (dired-efap-face :foreground "white"
                          :box (:line-width 2 :color border :style pressed-button))
         (show-paren-match :foreground "white" :weight extra-bold)
         (button :foreground "white" :weight semi-bold
                 :underline (:color bg-muted :style double-line)))))

  (neron-theme-create 'neron-myvariant my-colors my-overrides))

(provide-theme 'neron-myvariant)
#+end_src

Ensure this new file is somewhere in =custom-theme-load-path=.

To create a functional theme, the color palette provided to
=(neron-theme-create)= must contain an entry for every symbolic color
used by the default faces in =neron-theme--base-faces= (e.g.,
=fg-primary=, =accent-blue=, =border=, etc.). These are the colors needed to
render the base set of ~150 faces correctly.

- Then, the overrides argument can be used to:
  + Modify existing faces: Change the weight or slant, or point a face
    to a different color from your palette.
    * *NOTE*: this overrides the /whole/ face, i.e. default or inherited
      attributes will be overriden if e.g. only =:foreground= is set.
  + Customize new faces: Add face definitions not covered by the base.
  + Bypass the palette: Use a hardcoded hex color for a specific face
    instead of a symbolic name.

** The simplified plist faces syntax
#+begin_src emacs-lisp
'(
  (facename :face-attribute val)
 )
#+end_src
- where
  + =facename= is a face symbol as shown in =M-x describe-face=
  + =:face-attribute= is a [[https://www.gnu.org/software/emacs/manual/html_node/elisp/Face-Attributes.html][face attribute]].
  + =val= is the face attribute's value, some face attributes accept
    plist arguments.
