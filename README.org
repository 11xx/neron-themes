#+title: Neron Themes

A pair of neon-pastel color themes for Emacs: =neron-dark= and =neron-light=.

A theme written as hex colors looks right in a graphical frame and falls
apart in a terminal, where Emacs approximates each color on its own and
selection, diffs and subtle backgrounds can collapse into the same gray.
The Neron themes are defined once as a palette of named colors, and a
shared engine (=neron-theme-base.el=) derives the 256-color and 16-color
variant of every face from it. One theme then works in a GUI frame and
in =emacsclient -nw=, and a face can still pin its own fallback where the
derived one is not enough.

The name reads 666 as a gematria cipher for "Neron Caesar".

* Install

Requires Emacs 28.1.

#+begin_src emacs-lisp
(package-vc-install "https://github.com/11xx/neron-themes")
(load-theme 'neron-dark t)
#+end_src

or with =use-package= (Emacs 30):

#+begin_src emacs-lisp
(use-package neron-themes
  :vc (:url "https://github.com/11xx/neron-themes")
  :config (load-theme 'neron-dark t))
#+end_src

or with Elpaca:

#+begin_src emacs-lisp
(elpaca (neron-themes :host github :repo "11xx/neron-themes"))
#+end_src

The package adds its directory to =custom-theme-load-path=, so both themes
show up in =M-x load-theme=.

* Follow the system dark mode

With [[https://github.com/LionyxML/auto-dark-emacs][auto-dark]], the pair switches with the desktop:

#+begin_src emacs-lisp
(use-package auto-dark
  :custom (auto-dark-themes '((neron-dark) (neron-light)))
  :init (auto-dark-mode))
#+end_src

* Make a variant

A variant is a theme file on =custom-theme-load-path= that passes a
palette and face overrides to =neron-theme-base-create=:

#+begin_src emacs-lisp
;;; neron-myvariant-theme.el
(require 'neron-theme-base)

(deftheme neron-myvariant "My Neron variant.")

(let ((colors
       '((bg-primary      "#222222")
         (bg-secondary    "#27282c")
         (bg-hl           "#2f2f2f")
         (bg-selection    "#355565")
         (fg-primary      "#a6a8a9")
         (fg-secondary    "#cccccc")
         (fg-muted        "#707070")
         (accent-blue     "#69aaff")
         (accent-cyan     "#00bbb7")
         (accent-green    "#61bd09")
         (accent-magenta  "#ff77cf")
         (accent-orange   "#fd892c")
         (accent-purple   "#a89bff")
         (accent-red      "#f88785")
         (accent-warning  "#d2a022")
         (accent-yellow   "#b8aa07")
         (bg-diff-added   "#152615")
         (bg-diff-removed "#301d1e")
         (bg-diff-header  "#092147")
         (border          "#404047")
         (cursor          "#4455bb")
         (comment         "#bda38e")))
      (overrides
       '((show-paren-match :foreground "white" :weight extra-bold)
         (match :foreground "white" :background (:darken accent-blue 20)
                :box (:line-width 1 :color border)))))
  (neron-theme-base-create 'neron-myvariant colors overrides))

(provide-theme 'neron-myvariant)
#+end_src

The palette needs every color name the base faces use; the list above is
complete. An override replaces the whole face spec rather than merging into
it. Values may be palette names, literal colors, color expressions such as
=(:darken accent-blue 20)=, or a per-display plist such as
=(:gui bg-selection :256 "color24" :tty "blue")=. The engine's docstrings
in =neron-theme-base.el= list the rest. The =.el= files are tangled from
=neron-themes.org=.
