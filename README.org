#+title: Neron Themes

# Created: As package 2026-03-03 (originally from dotfiles 2022-07-07)

A pair of neon-pastel themes for Emacs (dark and light).

The name "Neron" refers to a interpretation of the number 666 as a
cipher for "Neron Caesar" in Hebrew gematria/isopsephy.

* Installation
The repository contains pre-generated, standalone theme files. You can
install directly from git using your preferred package manager.

** package.el (Emacs 29+)
If you're on Emacs 29 or newer, you can use the built-in =package-vc-install=:

#+begin_src emacs-lisp
(unless (package-installed-p 'neron-themes)
  (package-vc-install "https://codeberg.org/11xx/neron-themes"))
#+end_src

** straight.el
#+begin_src emacs-lisp
(straight-use-package
 '(neron-themes :host codeberg :repo "11xx/neron-themes"))
#+end_src

** Elpaca
#+begin_src emacs-lisp
(elpaca (neron-themes :host codeberg :repo "11xx/neron-themes"))
#+end_src

* Usage
The package automatically adds its installation directory to
=custom-theme-load-path=.

Available themes:
- =neron-dark=
- =neron-light=

e.g.
: (load-theme 'neron-dark)
: (load-theme 'neron-light)

-----

Example usage with [[https://www.emacswiki.org/emacs/SetupEl][setup.el]] + [[https://github.com/progfolio/elpaca][elpaca]] + [[https://github.com/LionyxML/auto-dark-emacs][auto-dark]]:
#+begin_src emacs-lisp
(elpaca (neron-themes :host codeberg
                      :repo "11xx/neron-themes"
                      :files ("neron-*-theme.el" "neron-themes.el")))

(setup (:elpaca auto-dark)
  (:load-after neron-themes)
  (setopt auto-dark-dark-theme 'neron-dark
          auto-dark-light-theme 'neron-light)
  (auto-dark-mode t)
  (:hide-mode))
#+end_src


* Development
The themes themselves (=neron-dark-theme.el= and =neron-light-theme.el=)
are generated from a shared base of faces and variable color names. If
you want to edit them, either change the color scheme/overrides inside
[[file:neron-theme-generator.el::(defconst neron-dark-colors][neron-theme-generator.el]] and re-generate the theme files with
#+begin_src shell
emacs -Q --batch -l neron-theme-generator.el --eval '(neron-theme--generate-default)'
#+end_src

or define new custom pallette and face overrides and use the helper
=(neron-theme-generate)=:
#+begin_src emacs-lisp
(defconst my-colors
  '((bg-primary      "#222222")
    (bg-secondary    "#27282c")
    (bg-hl           "#2f2f2f")

    (fg-primary      "#a6a8a9")
    (fg-secondary    "#cccccc")
    (fg-muted        "#707070")

    (accent-blue     "#69aaff")
    (accent-cyan     "#00bbb7")
    (accent-green    "#61bd09")
    (accent-magenta  "#ff77cf")
    (accent-orange   "#fd892c")
    (accent-purple   "#a89bff")
    (accent-red      "#f88785")
    (accent-warning  "#d2a022")
    (accent-yellow   "#b8aa07")
    ;; misc
    (bg-diff-added   "#152615")
    (bg-diff-removed "#301d1e")
    (bg-diff-header  "#092147")
    (border          "#404047")
    (cursor          "#4455bb")
    (comment         "#bda38e"))
  "Palette for neron-dark.")

(defconst my-overrides
  '((match :foreground "white" :background bg-hl
           :weight bold :slant i
           :box (:line-width 1 :color border)
           :underline (:style line :position -5))
    (isearch-fail :background "red" :foreground "white" :inherit match)
    (vertico-current :foreground "white" :background bg-hl
                     :weight bold :slant o :extend t)
    (dired-efap-face :foreground "white"
                     :box (:line-width 2 :color border :style pressed-button))
    (show-paren-match :foreground "white" :weight extra-bold)
    (button :foreground "white" :weight semi-bold
            :underline (:color bg-hl :style double-line)))
  "Face overrides for neron-dark.")

(neron-theme-generate 'myvariantname my-colors my-overrides)
#+end_src
- where
  + =myvariantname= will generate a theme called
    =neron-myvariantname-theme.el=.
  + Theme colors definition should follow variable names as the
    default faces defined in =(neron-theme--get-base-faces)= all use them.
  + Also, note the simplified syntax for faces, they will later be
    expanded to =custom-theme-set-faces= syntax by
    =(neron-theme--build-faces)=.


** The simplified plist faces syntax
#+begin_src emacs-lisp
'(
  (facename :face-attribute val)
 )
#+end_src
- where
  + =facename= is a face symbol as shown in =M-x describe-face=
  + =:face-attribute= is a [[https://www.gnu.org/software/emacs/manual/html_node/elisp/Face-Attributes.html][face attribute]].
  + =val= is the face attribute's value, some face attributes accept
    plist arguments.
